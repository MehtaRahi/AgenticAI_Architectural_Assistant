# Agentic AI Assistant for Architectural Design and Project Coordination

An AI-powered web application to assist architects and stakeholders by automating coordination tasks, design reviews, and research across multiple sources.

## Features
- **Project Context Management**: Maintain awareness of ongoing architectural projects.
- **Autonomous Task Execution**: Execute tool-based architectural tasks.
- **Design Review**: AI-driven architectural document and model review.
- **Automated Research**: Intelligent retrieval over building codes, standards, and guidelines.

## Tech Stack
- **Agent Orchestration**: LangGraph
- **LLM**: Ollama + Llama 3.1
- **RAG & Tools**: LangChain + ChromaDB
- **Backend API**: FastAPI + PostgreSQL
- **Frontend**: Streamlit
- **Document & BIM Parsing**: PyMuPDF, python-docx, ifcopenshell
- **Infrastructure**: Docker, GitHub Actions, MinIO, MLflow
